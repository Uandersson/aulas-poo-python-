## Conceitos de POO abordados

A programação orientada a objetos organiza o software em torno de entidades chamadas objetos. Os principais assuntos geralmente estudados incluem:

### 1. Classes e objetos
As classes servem como “modelo” para criar objetos. Um objeto é uma instância concreta da classe, com atributos e comportamentos.

### 2. Atributos e métodos
Os atributos representam as características dos objetos, enquanto os métodos definem as ações que eles podem executar.

### 3. Encapsulamento
Consiste em proteger os dados internos de uma classe e controlar o acesso a eles por meio de métodos, como getters e setters.

### 4. Herança
Permite criar novas classes a partir de classes existentes, reutilizando código e organizando melhor a hierarquia do sistema.

### 5. Polimorfismo
Permite que objetos de classes diferentes respondam ao mesmo método de formas específicas, tornando o código mais flexível e reutilizável.

### 6. Abstração
Envolve identificar apenas os aspectos relevantes de um sistema e esconder detalhes desnecessários.

### 7. Interfaces e classes abstratas
São mecanismos que ajudam a estruturar projetos mais organizados, com regras e comportamentos compartilhados.

### 8. Relacionamento entre classes
Inclui associação, agregação, composição e dependência, fundamentais para modelar sistemas mais complexos.

## Importância do estudo de POO

A Programação Orientada a Objetos é uma base essencial para o desenvolvimento de software moderno. Ela ajuda a criar sistemas mais:

- Organizados
- Reutilizáveis
- Escaláveis
- Fáceis de manter
- Menos propensos a erros

Essa abordagem é muito utilizada em aplicações web, desktop, mobile, bancos de dados, sistemas empresariais e jogos.
